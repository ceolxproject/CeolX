# Task: Course Builder UI - Masterclass Type

## Description

Implement a multi-step wizard UI for creating and editing Masterclass courses in the Mentor Web App. The wizard guides instructors through a structured process to define course metadata, create modules with lessons, add resources and assignments, configure community settings, set pricing, and review before publishing. The UI adapts based on course type (Masterclass vs Lesson) and supports saving as draft at any step for resuming later.

## Affected Apps/Packages

- Frontend: `@mentor/web` (Next.js, React)
- Shared components: `@mentor/ui` (Design system)
- Shared types: `@mentor/types`
- API client: `@mentor/api-client`

## UI Wizard Steps

### Step 1: Course Details

Define basic course metadata.

**Fields:**

- Course Title (text input, max 200 chars, required, word counter)
- Description (textarea, max 5000 chars, required, word counter)
- Category (dropdown, required, fetched from /api/v1/categories)
- Skill Level (radio buttons: Beginner, Intermediate, Advanced, required)
- Course Image/Thumbnail (image upload, aspect ratio 16:9, preview, optional at this stage)

**Actions:**

- Save Draft button (enabled at any step)
- Next button (validates all required fields)
- Back button (if returning from later step)

**Validation:**

- Show real-time validation feedback
- Highlight required fields not filled
- Prevent Next if required fields empty

### Step 2: Module Creation

Add and organize modules for the Masterclass.

**Features:**

- Add Module button
- Module list with:
  - Module title (editable inline)
  - Module description (editable in modal)
  - Lesson count badge
  - Drag-and-drop to reorder modules
  - Edit and Delete buttons per module
- Sort order managed via drag-and-drop (1, 2, 3, ...)

**Modal: Create/Edit Module**

- Module Title (text input, max 200 chars, required)
- Module Description (textarea, max 2000 chars, optional)
- Save button

**Validation:**

- Masterclass requires at least 1 module to proceed
- Module titles must be unique within course
- Module title required

**Actions:**

- Save Draft button
- Back button (to Step 1)
- Next button (requires ≥1 module)

### Step 3: Lesson Management (Per Module)

Add lessons to each module with video and basic metadata.

**Features:**

- Tab or collapsible section per module
- Lessons list showing:
  - Lesson title
  - Video status (uploaded/pending/error)
  - Duration (auto-populated after upload)
  - Edit and Delete buttons
- Add Lesson button per module
- Drag-and-drop to reorder lessons within module

**Modal: Create/Edit Lesson**

- Lesson Title (text input, max 200 chars, required)
- Lesson Description (textarea, max 3000 chars, optional)
- Video Upload (Mux Direct Upload, see video-upload-mux-direct.md)
  - Drag-and-drop area or file picker
  - Progress indicator during upload
  - Supported formats: MP4, MOV, AVI, MKV, WEBM
  - Max file size: 2GB
  - After upload: display video duration (from Mux)
  - Thumbnail preview (auto-generated by Mux)
- Save button

**Validation:**

- Lesson title required
- Video required for lesson
- Each module must have ≥1 lesson to publish
- Show validation errors clearly

**Actions:**

- Save Draft button
- Back button (to Step 2)
- Next button (requires ≥1 lesson per module)

### Step 4: Resources & Assignments

Add downloadable resources and assessments to lessons/course.

**Features:**

- Resource Management section:
  - List of course-level resources (applies to all lessons)
  - Add Resource button (opens resource upload modal)
  - Delete resource button
  - Resource type badges (PDF, ZIP, external link, etc.)
  - Download link generation
- Assignment/MCQ Management section:
  - List of course-level and lesson-level assignments
  - Create Assignment button (opens assignment builder modal)
  - Edit/Delete buttons per assignment
  - Question preview

**Resource Upload Modal**

- File upload (PDF, DOC/DOCX, ZIP, MP3, MP4) or external link URL
- For files: upload to R2, show progress
- For URLs: validate and store URL
- Display uploaded resources with file size
- See resource-upload-management.md for details

**Assignment Builder Modal**

- Assignment Title (text input, required)
- Assignment Type: Per Lesson or Per Course (radio)
- Add Question button
- Questions list:
  - Question text (textarea)
  - Question type: Multiple Choice (JSONB options)
  - Options list (add/edit/delete options)
  - Mark correct option(s)
  - Edit/Delete question buttons
- Save Assignment button
- See assignment-mcq-creation.md for details

**Actions:**

- Save Draft button
- Back button (to Step 3)
- Next button (optional, no hard requirement)

### Step 5: Community Settings

Configure course community features.

**Features:**

- Enable Community checkbox (toggle)
- If enabled, show:
  - Community Guidelines textarea (max 2000 chars)
  - Allowed Post Types checkboxes:
    - Text posts
    - Images
    - Videos
    - Audio
  - Default moderation level (radio: None, Strict, Moderate)
- Preview of community settings

**Actions:**

- Save Draft button
- Back button (to Step 4)
- Next button

### Step 6: Pricing & Enrollment

Set course pricing and enrollment options.

**Features:**

- Pricing Model (radio buttons):
  - Free
  - Paid (input for price in dollars/cents)
- Currency selector (default: USD)
- Display calculated price in cents for API
- Enrollment Options:
  - Max enrollments (optional, leave blank for unlimited)
  - Enrollment window (optional date range)
- Price preview and notes

**Validation:**

- If paid, price must be > 0
- If max enrollments set, must be positive integer

**Actions:**

- Save Draft button
- Back button (to Step 5)
- Next button

### Step 7: Review & Publish

Summary view of entire course before publishing.

**Features:**

- Summary cards showing:
  - Course title, description, category, skill level
  - Modules count, total lessons count
  - Resources count, assignments count
  - Community enabled/disabled
  - Pricing (free or price)
- Editable fields: Click to jump back to relevant step
- Publish Readiness Validation (see publish-validation-flow.md)
  - ✓ or ✗ badges for each requirement
  - Clear error messages for missing requirements
  - Prevent publish if validation fails

**Actions:**

- Back button (to Step 6)
- Publish button (disabled if validation fails)
- Save as Draft button (always available)
- Preview Course button (opens preview modal or new tab)

**Post-Publish:**

- Show success message
- Redirect to course detail page or dashboard
- Option to view published course or create another

### State Management

Use React Context or Zustand for wizard state:

```typescript
interface CourseBuilderState {
  courseId: string;
  currentStep: number;
  formData: {
    // Step 1
    title: string;
    description: string;
    category: string;
    skillLevel: string;
    thumbnailUrl?: string;

    // Step 2
    modules: Module[];

    // Step 3
    lessons: Lesson[];

    // Step 4
    resources: Resource[];
    assignments: Assignment[];

    // Step 5
    communityEnabled: boolean;
    communityGuidelines?: string;
    allowedPostTypes: string[];

    // Step 6
    pricingModel: "free" | "paid";
    price?: number;
    currency: string;
    maxEnrollments?: number;
  };
  isDraft: boolean;
  unsavedChanges: boolean;

  // Actions
  setStep: (step: number) => void;
  updateFormData: (data: Partial<CourseBuilderState["formData"]>) => void;
  saveDraft: () => Promise<void>;
  publishCourse: () => Promise<void>;
}
```

### Auto-Save Strategy

- Debounce form changes by 3 seconds
- Save to draft API on debounce
- Show "saving..." indicator during save
- Display "all changes saved" confirmation
- Handle save errors gracefully

### Mux Video Upload Integration

- Use @mux/mux-node for server-side API calls
- Client uses Mux Direct Upload SDK
- See video-upload-mux-direct.md for full details
- Display progress bar during upload
- Retry on failure with exponential backoff
- Handle network interruptions gracefully

### Validation Messaging

- Use toast notifications for success/error feedback
- Show field-level validation errors inline
- Collect all errors and display summary before publish
- Use icons: ✓ (valid), ✗ (invalid), ⚠ (warning)

### Performance Considerations

- Lazy load modals and heavy components
- Virtualize long lists (many modules/lessons)
- Debounce file uploads to prevent rapid successive uploads
- Cache category list and skill levels
- Use React.memo for step components to prevent re-renders

### Accessibility

- Label all form inputs with <label> elements
- Support keyboard navigation (Tab, Enter, Escape)
- Announce step changes and validation errors to screen readers
- Ensure drag-and-drop is keyboard accessible (arrow keys fallback)
- Color contrast meets WCAG AA standards
