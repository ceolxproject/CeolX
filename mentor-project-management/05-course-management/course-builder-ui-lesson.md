# Task: Course Builder UI - Lesson Type

## Description

Implement a simplified multi-step wizard UI for creating and editing Lesson-type courses in the Mentor Web App. A Lesson is a single standalone learning item with a video, optional resources, and assignments. The wizard is streamlined compared to Masterclass (no modules step) and guides instructors through content details, video upload, optional linking to a Masterclass, resources/assignments, pricing, and review/publish.

## Affected Apps/Packages

- Frontend: `@mentor/web` (Next.js, React)
- Shared components: `@mentor/ui` (Design system)
- Shared types: `@mentor/types`
- API client: `@mentor/api-client`

## UI Wizard Steps

### Step 1: Lesson Details

Define basic lesson metadata.

**Fields:**

- Lesson Title (text input, max 200 chars, required, word counter)
- Description (textarea, max 5000 chars, required, word counter)
- Category (dropdown, required, fetched from /api/v1/categories)
- Skill Level (radio buttons: Beginner, Intermediate, Advanced, required)
- Lesson Image/Thumbnail (image upload, aspect ratio 16:9, preview, optional)

**Actions:**

- Save Draft button (enabled at any step)
- Next button (validates required fields)
- Back button (if resuming from draft)

**Validation:**

- Real-time validation feedback
- Highlight required fields
- Prevent Next if fields empty

### Step 2: Video Upload

Upload the lesson's primary video content.

**Features:**

- Video Upload section with Mux Direct Upload
  - Drag-and-drop area or file picker
  - Supported formats: MP4, MOV, AVI, MKV, WEBM
  - Max file size: 2GB
  - Progress bar during upload
  - Upload speed indicator
  - Cancel button during upload
- Video preview after upload
  - Thumbnail (auto-generated by Mux)
  - Video duration (auto-populated from Mux asset)
  - Mux playback URL stored
- Replace Video button (if editing existing lesson)
  - Triggers video replacement flow (see video-replacement-flow.md)

**Validation:**

- Video upload required to proceed
- Support for chunked uploads (for large files)
- Timeout handling and retry logic
- Clear error messages for failed uploads

**Actions:**

- Save Draft button
- Back button (to Step 1)
- Next button (requires video upload)

### Step 3: Link to Masterclass (Optional)

Optionally link this lesson to an existing Masterclass.

**Features:**

- Link to Masterclass checkbox (toggle)
- If enabled:
  - Masterclass selector dropdown (fetches instructor's published Masterclasses)
  - Shows Masterclass title, module count, lesson count
  - Confirmation message: "This lesson will be associated with [Masterclass Name]"
- If not linked:
  - Lesson remains standalone
  - Note: "This lesson is standalone and can be enrolled directly"

**Purpose:**

- Allows instructors to package single lessons within larger courses
- Linked lessons inherit some course context (breadcrumb, navigation)
- Standalone lessons are directly discoverable and enrollable

**Validation:**

- If linked, must select valid Masterclass
- No circular linking (lesson cannot be in its own Masterclass)

**Actions:**

- Save Draft button
- Back button (to Step 2)
- Next button (optional linking)

### Step 4: Resources & Assignments

Add downloadable resources and assessments.

**Features:**

- Resource Management section:
  - List of lesson-level resources
  - Add Resource button (opens resource upload modal)
  - Delete resource button per resource
  - Resource type badges (PDF, ZIP, external link, etc.)
  - Download link generation
  - File size display
- Assignment/MCQ Management section:
  - List of lesson-level assignments
  - Create Assignment button (opens assignment builder modal)
  - Edit/Delete buttons per assignment
  - Question preview

**Resource Upload Modal**

- File upload (PDF, DOC/DOCX, ZIP, MP3, MP4) or external link URL
- For files: upload to R2, show progress
- For URLs: validate and store URL
- Display uploaded resources with file size
- See resource-upload-management.md for details

**Assignment Builder Modal**

- Assignment Title (text input, required)
- Assignment Type: always "per-lesson" for Lesson type
- Add Question button
- Questions list:
  - Question text (textarea)
  - Question type: Multiple Choice
  - Options list (add/edit/delete)
  - Mark correct option(s)
  - Edit/Delete question buttons
- Save Assignment button
- See assignment-mcq-creation.md for details

**Actions:**

- Save Draft button
- Back button (to Step 3)
- Next button (optional, no hard requirement)

### Step 5: Pricing

Set lesson pricing (if applicable when not linked to paid Masterclass).

**Features:**

- Pricing Model (radio buttons):
  - Free (default if linked to paid Masterclass)
  - Paid (input for price in dollars/cents)
- Currency selector (default: USD)
- Display calculated price in cents for API
- Note: "If linked to a Masterclass, learners access via Masterclass enrollment"
- Price preview

**Validation:**

- If paid, price must be > 0
- If linked to Masterclass, show note about pricing inheritance

**Actions:**

- Save Draft button
- Back button (to Step 4)
- Next button

### Step 6: Review & Publish

Summary view of lesson before publishing.

**Features:**

- Summary cards showing:
  - Lesson title, description, category, skill level
  - Video duration
  - Masterclass link (if applicable)
  - Resources count, assignments count
  - Pricing (free or price)
- Editable fields: Click to jump back to relevant step
- Publish Readiness Validation (see publish-validation-flow.md)
  - ✓ or ✗ badges for requirements:
    - Title required
    - Description required
    - Category required
    - Skill level required
    - Video uploaded
    - Thumbnail set (optional but recommended)
  - Clear error messages for missing requirements
  - Prevent publish if validation fails

**Actions:**

- Back button (to Step 5)
- Publish button (disabled if validation fails)
- Save as Draft button (always available)
- Preview Lesson button (opens preview modal or new tab)

**Post-Publish:**

- Show success message
- Redirect to lesson detail page or dashboard
- Option to view published lesson or create another

### State Management

Use React Context or Zustand for wizard state:

```typescript
interface LessonBuilderState {
  lessonId: string;
  currentStep: number;
  formData: {
    // Step 1
    title: string;
    description: string;
    category: string;
    skillLevel: string;
    thumbnailUrl?: string;

    // Step 2
    videoMuxAssetId: string;
    videoMuxPlaybackId: string;

  publishLesson: () => Promise<void>;

```

### Masterclass Linking Logic

When user selects a Masterclass:

1. Fetch linked Masterclass details for display
2. Store `linkedMasterclassId` in lesson metadata
3. At publish time, verify Masterclass is published
4. On learner enrollment: if linking to paid Masterclass, lesson access governed by Masterclass enrollment

### Video Upload Integration

- Use Mux Direct Upload SDK
- For Lesson type, ensure exactly 1 video per lesson
- Store `mux_asset_id`, `mux_playback_id`, and `video_duration`
- See video-upload-mux-direct.md for detailed integration

### Auto-Save Strategy

- Debounce form changes by 3 seconds
- Save to draft API on debounce (PUT /api/v1/courses/{courseId})
- Show "saving..." indicator during save
- Display "all changes saved" confirmation
- Handle save errors gracefully with retry

### Validation Messaging

- Use toast notifications for success/error feedback
- Show field-level validation errors inline
- Collect all errors and display summary before publish
- Use icons: ✓ (valid), ✗ (invalid), ⚠ (warning)

### Performance Considerations

- Lazy load modals and heavy components
- Cache Masterclass list (instructor's published courses)
- Debounce file uploads to prevent rapid successive uploads
- Cache category list and skill levels
- Use React.memo for step components to prevent re-renders

### Accessibility

- Label all form inputs with <label> elements
- Support keyboard navigation (Tab, Enter, Escape)
- Announce step changes and validation errors to screen readers
- Color contrast meets WCAG AA standards
- Video player must be keyboard accessible

### Simplified Workflow for Lessons

Lesson type has fewer steps than Masterclass because:

- No module creation (single content item)
- No need to manage multiple lessons
- Masterclass linking is optional, not required
- Focus is on content quality and single video upload
