# Apple Sign-In

## Description

Implement Apple Sign-In via BetterAuth. Support both web and mobile implementations. Handle special cases where Apple only provides user name on first authentication. Required for App Store compliance on iOS apps. Supports account creation and existing account linking.

## Affected Apps/Packages

- `packages/auth`
- Frontend: All three web apps
- Mobile: React Native Expo app
- Backend: Hono API with BetterAuth OAuth integration

## API Endpoints

### GET /auth/apple

Initiate Apple OAuth flow (web apps).

**Query Parameters**:

- `redirect_uri`: Where to send user after auth
- `state`: CSRF token (generated by BetterAuth)

**Behavior**:

- Redirects to Apple login screen
- Shows privacy notice and app information
- Returns authorization code and user info

### POST /auth/apple/callback

Handle Apple OAuth callback (internal, handled by BetterAuth).

**Request Body** (form-encoded from Apple):

```
code=<authorization_code>
state=<csrf_token>
user=<JSON_string>
id_token=<JWT_token>
```

**Apple User Object** (only on first auth):

```json
{
  "name": {
    "firstName": "John",
    "lastName": "Doe"
  },
  "email": "john@privaterelay.appleid.com"
}
```

**Response** (Redirects to frontend with session):

```
Redirect to: <FRONTEND_URL>?status=success
Set-Cookie: authToken=<session_token>
```

### GET /auth/user/apple-email

Get real Apple email address (hidden behind Private Relay by default).

**Response** (200 OK):

```json
{
  "realEmail": "john.doe@example.com",
  "isPrivateRelay": true,
  "linkedAt": "2024-02-18T10:30:00Z"
}
```

## Requirements

### Apple OAuth Configuration

- Enroll in Apple Developer Program
- Create App ID with Sign in with Apple capability
- Register Services ID (for web)
- Create private key for server communication
- Register allowed domains and redirect URLs:
  - `https://api.example.com/auth/apple/callback` (web)
  - `https://learn.example.com` (learner web)
  - `https://teach.example.com` (mentor web)
  - `https://admin.example.com` (admin web)
  - `example.com` (primary domain)
  - Native app scheme: `mentor://oauth/apple` (mobile)

### Apple Developer Configuration

- **Team ID**: 10-digit identifier (from Apple Dev account)
- **Service ID**: Identifier for web authentication
- **Key ID**: From private key
- **Private Key**: P8 file (keep secure in environment)
- **Bundle ID**: `com.example.app` for mobile

### BetterAuth Apple Provider Configuration

```typescript

    },
```

### User Name Handling

Apple only provides user name during initial authorization:

- **First Auth**: User object contains `name.firstName` and `name.lastName`
- **Subsequent Auths**: User object is empty (name not re-transmitted)
- **Storage**: Store full name on first auth to `user.name` column
- **Privacy Relay**: Apple provides email, not real email (user can hide)

### Account Creation Flow

- User initiates Apple Sign-In
- Apple returns user object with email and name (first time only)
- **New User**:
  - Create user account with email from Apple
  - Set name from Apple user object (if provided)
  - If no name provided, prompt user to enter name
  - Set `emailVerified: true` (Apple verifies email)
  - Create `account` record linking Apple provider
  - Default role: `learner`
- **Existing User**:
  - Check if user with email exists
  - Link Apple account to existing user (federated identity)

### Account Linking

- Support linking Apple to existing email/password account
- Require re-authentication if session > 15 minutes old
- Display confirmation modal
- Store in `account` table:
  - `userId`
  - `provider`: 'apple'
  - `providerAccountId`: Apple's user ID
  - `displayName`, `email`
  - `linkedAt` timestamp

### Private Relay Email Handling

- Apple provides email: `<random>@privaterelay.appleid.com`
- User can choose to share real email or remain private
- If user shares real email:
  - Store in separate field: `appleRealEmail`
  - Use for account recovery and notifications
- If user keeps private:
  - Use Private Relay email for communications
  - Clearly inform user in emails that address is relay

### Session Creation

- Follow same session creation as email/password signin (task 04)
- Set session expiry: 30 days learner, 24 hours admin
- Store user agent and IP address
- Set secure cookies with HttpOnly, Secure, SameSite

### iOS App Store Compliance

- Apple Sign-In is required if using social login
- Must appear in Sign-In options with equal prominence
- Cannot require Apple Sign-In (user choice)
- Display Apple privacy notice clearly

### Error Handling

- User cancels authentication: Show message, return to login
- Apple API unavailable: Show error and fallback options
- Email already linked: Ask user to sign in with that method
- Missing name on first auth: Prompt user to provide name

## Technical Notes

### Apple JWT Client Secret Generation

Apple requires dynamic client secret (JWT) for token endpoint:

```typescript
import crypto from "crypto";
import jwt from "jsonwebtoken";

function generateAppleClientSecret(): string {
  const privateKey = process.env.APPLE_PRIVATE_KEY; // P8 format
  const teamId = process.env.APPLE_TEAM_ID;
  const keyId = process.env.APPLE_KEY_ID;
  const clientId = process.env.APPLE_SERVICE_ID;

  return jwt.sign({}, privateKey, {
    algorithm: "ES256",
    expiresIn: "5m",
    issuer: teamId,
    subject: clientId,
    keyid: keyId,
  });
}
```

### Apple JWT Validation

```typescript
import jwt from "jsonwebtoken";

async function validateAppleJWT(idToken: string): Promise<AppleJWTPayload> {
  // Get Apple's public keys
  const response = await fetch("https://appleid.apple.com/auth/keys");
  const { keys } = await response.json();

  // Decode and verify JWT
  try {
    return jwt.verify(idToken, keys, {
      algorithms: ["RS256", "ES256"],
      issuer: "https://appleid.apple.com",
      audience: process.env.APPLE_SERVICE_ID,
    });
  } catch (error) {
    throw new Error("Invalid Apple JWT");
  }
}

interface AppleJWTPayload {
  iss: string;
  sub: string; // Apple user ID
  aud: string;
  iat: number;
  exp: number;
  email: string;
  email_verified: boolean;
  auth_time: number;
  nonce_supported: boolean;
}
```

### User Name Handling Logic

```typescript
async function handleAppleSignIn(
  idToken: string,
  userObject: AppleUserObject | null
) {
  const claims = await validateAppleJWT(idToken);
  const appleUserId = claims.sub;
  const email = claims.email;

  // Check if user exists
  let user = await findUserByEmail(email);

  if (!user) {
    // New user - create account
    let name = "Apple User"; // Default name

    if (userObject?.name) {
      // Only provided on first auth
      name = `${userObject.name.firstName} ${userObject.name.lastName}`.trim();
    }

    user = await createUser({
      email,
      name,
      emailVerified: true,
      role: "learner",
    });
  }

  // Link Apple account
  await linkAccount({
    userId: user.id,
    provider: "apple",
    providerAccountId: appleUserId,
    idToken,
    email,
  });

  // Handle Private Relay email
  if (userObject?.email?.includes("privaterelay")) {
    await saveAppleUserDetails({
      userId: user.id,
      isPrivateRelay: true,
      revealedAt: null,
    });
  }

  return createSession(user);
}
```

### Mobile Implementation Example (Expo)

```typescript
// app/auth/AppleSignIn.tsx
import * as AppleAuthentication from 'expo-apple-authentication';
import * as SecureStore from 'expo-secure-store';
import { useContext } from 'react';

export function AppleSignInButton() {
  const { setUser } = useContext(AuthContext);

  const handleAppleSignIn = async () => {
    try {
      const credential = await AppleAuthentication.signInAsync({
        requestedScopes: [
          AppleAuthentication.AppleAuthenticationScope.FULL_NAME,
          AppleAuthentication.AppleAuthenticationScope.EMAIL,
        ],
      });

      // Send to backend
      const response = await fetch(`${API_URL}/auth/apple/mobile`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          identityToken: credential.identityToken,
          user: credential.user, // Contains name and email
        }),
      });

      if (!response.ok) throw new Error('Auth failed');

      const { sessionToken, user } = await response.json();

      await SecureStore.setItemAsync('authToken', sessionToken);
      setUser(user);
    } catch (error) {
      if (error.code !== 'ERR_CANCELED') {
        console.error('Apple sign-in error:', error);
      }
    }
  };

  return (
    <AppleAuthentication.AppleAuthenticationButton
      buttonType={AppleAuthentication.AppleAuthenticationButtonType.SIGN_IN}
      buttonStyle={AppleAuthentication.AppleAuthenticationButtonStyle.BLACK}
      cornerRadius={5}
      style={{ height: 48, marginVertical: 10 }}
      onPress={handleAppleSignIn}
    />
  );
}
```
