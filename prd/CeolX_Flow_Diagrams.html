Booking State Machine
PENDING
Initial state when either an Artist submits an application or a Venue sends an invitation. No action taken yet by the recipient.
Triggered by: Application or Invitation sent
ACCEPTED
Recipient has confirmed. Artist is now linked to the event as a performer. Both parties are notified.
Triggered by: Recipient accepts
REJECTED
Recipient declined the request. Terminal state — no further action. Sender is notified.
Triggered by: Recipient rejects
CANCELLED
Either the Artist or the Venue cancels a previously accepted booking. Available at any time post-acceptance.
Triggered by: Either party cancels

GDPR Compliance Flow (Mandatory — Irish Client)
01
Consent at Sign-Up
User must accept Privacy Policy and Terms of Service. Consent for location tracking and marketing comms collected explicitly.
02
Location Data
Collected on-demand only (app in use). Not continuously tracked in background. User can revoke at any time via device settings.
03
Right to Erasure
Users can request account deletion. Personal data is anonymised. Non-personal content (event structures) retained for platform integrity.
04
Data Portability
Users can export their personal data on request (Article 20). Delivered as a structured file.
05
Data Retention
Inactive accounts flagged after 24 months. Defined retention periods for all personal data categories.
