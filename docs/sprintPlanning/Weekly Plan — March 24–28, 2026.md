★ Insight ─────────────────────────────────────
Why enums over free-text for categories matters now: If event categories aren't locked in before M1-T2 migrations run, you'll face a schema  
 migration in week 5-7 (M4) when events are being built. Drizzle + Neon branching makes this manageable, but it's cheaper to decide now. A  
 simple starting set (Traditional, Folk, Rock, Jazz, Classical, Electronic, Other) can be extended later.

BTS scaffolded more than M1-T1: better-t-stack gave you BetterAuth tables + tRPC wiring out of the box. M1-T2 now only needs the 12  
 CeolX-specific tables — auth tables already exist.

GIST index is the performance-critical piece of M1-T2: Every map load hits events with a bounding box query. Without CREATE INDEX USING GIST  
 (ll_to_earth(lat, lng)) (or PostGIS equivalent), map queries will full-scan the events table. This is the one index that absolutely cannot be
added "later."
