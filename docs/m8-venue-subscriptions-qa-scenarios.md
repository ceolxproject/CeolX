## System Overview

A venue pays €19.99/month or €199/year after a **6-month free trial** with the card taken
up front. Nothing about payment appears in the app (Apple Rule 3.1.1): the venue taps
**Activate Profile**, the server emails a one-time link, and the link 302s straight to
Stripe Checkout. A Stripe webhook is the **only** writer of subscription state.

`venue_profiles.subscription_status` has five values, and visibility is derived from it —
never stored:

| Status      | Means                                | Publicly visible | May publish |
| ----------- | ------------------------------------ | ---------------- | ----------- |
| `inactive`  | Never completed payment setup        | No               | No          |
| `trialing`  | Card on file, inside the trial       | Yes              | Yes         |
| `active`    | Paying                               | Yes              | Yes         |
| `past_due`  | Charge failed, Stripe still retrying | Yes              | Yes         |
| `cancelled` | Stripe gave up, or period elapsed    | No               | No          |

**Key properties / configuration:**

| Property                            | Effect                                                                                                                                                          |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VENUE_GATE_ENABLED`                | Master switch. `false` (shipping default) makes every venue visible regardless of status. Ships dark because every production venue is still `inactive` (O-08). |
| `STRIPE_TRIAL_DAYS` (183)           | Trial length, passed per Checkout Session — **not** on the Price, so D-42 can withhold it.                                                                      |
| `ACTIVATION_TOKEN_TTL_MINUTES` (45) | One-time link lifetime.                                                                                                                                         |
| `billing_blocked`                   | Boolean, not a status. Set on chargeback and **never cleared by a webhook**; overrides status everywhere.                                                       |
| Stripe retry schedule               | **This is the grace window** since D-33 was revised. Live-mode-only setting, currently **15 days**, D-33 wants **7**.                                           |
| `automatic_tax`                     | Deliberately **off** — €19.99 is VAT-inclusive but no VAT is calculated until Chongie registers (D-66).                                                         |
